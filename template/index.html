planet eniehack

Planet DebianやPlanet masakaのように、僕個人の最新情報を1つのページにまとめたものです。

データソースは以下の通りです:

    {{ range $k, $v := .Sites}}
  • {{$v.Title}}
    • {{ end }}

{{ range $i, $k := .Keys -}}

{{- $k -}}

    {{ range $j, $post := (index $.Posts $k) -}} {{ $site := index $.Sites $post.Src }}

  • {{- $post.Content -}}

    ({{- $post.ParsedDate.Format "15:04" -}})
    • {{ end -}}
{{ end -}}

planet-someone(revision: {{ $.Meta.Version }})
